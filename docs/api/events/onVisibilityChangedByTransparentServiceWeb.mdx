# `onVisibilityChangedByTransparentServiceWeb`

투명 서비스 웹(Transparent Service Web)이 보이거나 숨겨질 때 호출되는 이벤트를 구독합니다. 콜백은 현재 가시성 상태를 `isVisible: boolean`으로 전달합니다. 반환된 unsubscribe 함수를 호출하면 구독이 해제됩니다.

## 시그니처

```ts
import { onVisibilityChangedByTransparentServiceWeb } from '@apps-in-toss/web-framework';

const unsubscribe = onVisibilityChangedByTransparentServiceWeb({
  options: { callbackId: 'my-callback-id' },   // callbackId: string
  onEvent: (isVisible) => { /* isVisible: boolean */ },
  onError: (err) => { /* err: Error */ },
});
// unsubscribe(): () => void — 리스너 해제
```

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | :-: | --- |
| `options.callbackId` | `string` | ✓ | 콜백을 식별하는 고유 ID. 동일 ID로 다시 구독하면 이전 구독을 덮어씁니다. |
| `onEvent` | `(isVisible: boolean) => void` | ✓ | 가시성이 변경될 때 호출되는 핸들러. `isVisible`이 `true`이면 화면에 보이는 상태, `false`이면 숨겨진 상태입니다. |
| `onError` | `(error: Error) => void` | — | 이벤트 처리 중 에러 발생 시 호출되는 핸들러. |

## 반환값

- `() => void` — unsubscribe 함수. 이벤트 구독을 해제합니다. `useEffect` 반환값으로 사용하세요.

## 권한

권한이 필요하지 않습니다 — `onVisibilityChangedByTransparentServiceWeb`은 별도의 `PermissionName`에 바인딩되지 않습니다.

## 예제

### 최소 예제 — useEffect에서 가시성 구독

```tsx
import { onVisibilityChangedByTransparentServiceWeb } from '@apps-in-toss/web-framework';
import { useEffect, useState } from 'react';

function TransparentWebPage() {
  const [isVisible, setIsVisible] = useState(false);

  useEffect(() => {
    const unsubscribe = onVisibilityChangedByTransparentServiceWeb({
      options: { callbackId: 'transparent-web-visibility' },
      onEvent: (visible) => {
        setIsVisible(visible);
      },
      onError: (err) => {
        console.error('가시성 이벤트 오류:', err);
      },
    });
    return unsubscribe;
  }, []);

  return <main>{isVisible ? '화면에 표시 중' : '숨겨짐'}</main>;
}
```
