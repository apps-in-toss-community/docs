# `generateHapticFeedback`

장치의 진동 모터를 제어해 지정한 타입의 햅틱 피드백을 발생시킵니다. 버튼 탭 확인, 오류 알림, 완료 축하 등 중요한 상호작용 순간에 촉각 단서를 추가합니다.

## 시그니처

```ts
import { generateHapticFeedback } from '@apps-in-toss/web-framework';

type HapticFeedbackType =
  | 'tickWeak'
  | 'tap'
  | 'tickMedium'
  | 'softMedium'
  | 'basicWeak'
  | 'basicMedium'
  | 'success'
  | 'error'
  | 'wiggle'
  | 'confetti';

declare function generateHapticFeedback(options: { type: HapticFeedbackType }): Promise<void>;
```

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | :-: | --- |
| `options.type` | `HapticFeedbackType` | ✓ | 피드백 강도와 느낌. 자세한 타입 설명은 [네임스페이스 개요의 "피드백 타입"](/api/haptic#피드백-타입)을 참고하세요. |

## 반환값

- `Promise<void>` — 진동 요청이 전달되면 resolve.
- devtools mock 환경에서는 실제 진동 없이 콘솔에 로그만 출력됩니다. 실제 피드백은 토스 앱 내부(iOS / Android)에서만 확인할 수 있습니다.

## 권한

권한이 필요하지 않습니다 — `haptic` 네임스페이스는 별도의 `PermissionName`에 바인딩되지 않습니다. 권한이 필요한 다른 네임스페이스의 일반적인 처리 흐름은 [Guides — 권한 처리 패턴](/guides/permissions-pattern)을 참고하세요.

## 예제

### 최소 예제

```tsx
import { generateHapticFeedback } from '@apps-in-toss/web-framework';

await generateHapticFeedback({ type: 'success' });
```

### 실전 예제 — 결제 완료 버튼

```tsx
import { generateHapticFeedback } from '@apps-in-toss/web-framework';
import { useState } from 'react';

export function PayButton() {
  const [status, setStatus] = useState<'idle' | 'pending' | 'done' | 'error'>('idle');

  async function handlePay() {
    setStatus('pending');
    try {
      // 앱 자체 결제 로직 (예시)
      await submitPayment();
      await generateHapticFeedback({ type: 'success' });
      setStatus('done');
    } catch {
      await generateHapticFeedback({ type: 'error' });
      setStatus('error');
    }
  }

  return (
    <button type="button" onClick={handlePay} disabled={status === 'pending'}>
      {status === 'pending' ? '처리 중…' : '결제하기'}
    </button>
  );
}
```
