# `haptic`

장치의 진동 모터를 제어해 햅틱 피드백을 생성하거나, Base64 인코딩된 데이터를 로컬에 파일로 저장합니다. 버튼 탭·오류·완료 같은 순간에 촉각 단서를 추가하면 UX가 한층 생생해집니다.

## 메서드

| 메서드 | 용도 |
| --- | --- |
| [`generateHapticFeedback`](/api/haptic/generateHapticFeedback) | 지정한 피드백 타입으로 진동을 발생시킵니다. |
| [`saveBase64Data`](/api/haptic/saveBase64Data) | Base64 인코딩된 데이터를 파일로 저장합니다. |

## 권한

권한이 필요하지 않습니다. `haptic` 네임스페이스는 별도의 `PermissionName`에 바인딩되지 않으며, `getPermission()` / `openPermissionDialog()` 유틸도 노출하지 않습니다. 권한이 필요한 다른 네임스페이스에서의 일반적인 처리 흐름은 [Guides — 권한 처리 패턴](/guides/permissions-pattern)을 참고하세요.

## 피드백 타입

`generateHapticFeedback`은 `type` 파라미터로 피드백의 강도와 느낌을 구분합니다.

| 타입 | 분류 | 사용 상황 |
| --- | --- | --- |
| `tickWeak` | tick | 가벼운 목록 스크롤·세그먼트 이동 |
| `tickMedium` | tick | 중간 강도 탭·스텝 이동 |
| `tap` | 일반 | 버튼 탭 확인 |
| `softMedium` | soft | 토글·슬라이더 조작 |
| `basicWeak` | basic | 경미한 알림·힌트 |
| `basicMedium` | basic | 일반 선택·확인 |
| `success` | 의미론적 | 결제 완료·저장 성공 |
| `error` | 의미론적 | 오류·실패 |
| `wiggle` | 강조 | 경고·흔들기 |
| `confetti` | 강조 | 축하·보상 지급 |

## UX 가이드

- **사용자 행동에 반응하세요.** 버튼 탭, 스와이프 완료, 결제 확정 같은 사용자 의도가 명확한 시점에만 진동을 사용하세요. 배경 작업이나 자동 이벤트에 사용하면 예기치 않게 느껴집니다.
- **과도한 사용을 피하세요.** 진동이 너무 자주 발생하면 사용자가 무감각해집니다. 중요한 순간에만 활용하면 효과가 유지됩니다.
- **의미론적 타입을 우선하세요.** `success`·`error` 같은 시맨틱 타입은 의도가 명확하고 미래 SDK 업데이트에서 더 안정적으로 유지됩니다. 원하는 의미론적 타입이 없을 때만 강도 기반 타입을 쓰세요.
- **저전력 모드를 존중하세요.** 일부 디바이스에서는 저전력 모드 시 진동이 무시될 수 있습니다. 햅틱은 시각적 피드백을 보완하는 수단이지 대체가 아닙니다.
