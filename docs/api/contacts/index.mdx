# `contacts`

연락처 목록 페이지네이션 조회, 친구 공유 리워드(Viral), 기기 앨범 사진 가져오기를 제공하는 함수 모음입니다. `fetchContacts`와 `fetchAlbumPhotos`는 `Promise`를 반환하고, `contactsViral`은 이벤트 콜백 기반입니다.

:::info 비공식 문서
이 페이지는 커뮤니티가 작성한 설명입니다. SDK의 동작은 상위의 [`@apps-in-toss/web-framework`](https://www.npmjs.com/package/@apps-in-toss/web-framework) 배포본을 기준으로 합니다.
:::

## 메서드

| 메서드 | 반환 타입 | 용도 |
| --- | --- | --- |
| [`contactsViral`](/api/contacts/contactsViral) | `() => void` | 연락처 기반 친구 공유 리워드 모듈을 엽니다. 이벤트 콜백으로 결과를 받습니다. |
| [`fetchAlbumPhotos`](/api/contacts/fetchAlbumPhotos) | `Promise<ImageResponse[]>` | 기기 앨범에서 사진 목록을 가져옵니다. |
| [`fetchContacts`](/api/contacts/fetchContacts) | `Promise<ContactResult>` | 사용자 연락처 목록을 페이지 단위로 조회합니다. |

## 권한

네임스페이스 내 함수별로 별도의 권한이 필요합니다.

| 메서드 | PermissionName |
| --- | --- |
| `contactsViral` | `contacts` |
| `fetchAlbumPhotos` | `photos` |
| `fetchContacts` | `contacts` |

`fetchContacts`와 `contactsViral`은 동일한 `contacts` 권한을 공유하므로, 하나의 권한 확인으로 두 함수 모두 사용할 수 있습니다. `fetchAlbumPhotos`는 별도의 `photos` 권한이 필요합니다.

- 권한이 **`denied`** 상태이면 호출 시 실패합니다. `getPermission()`으로 미리 확인하세요.
- 아직 결정되지 않은 상태(`notDetermined`)라면 `openPermissionDialog()`로 다이얼로그를 띄우세요.

상세 처리 패턴은 [Guides — 권한 처리 패턴](/guides/permissions-pattern)을 참고하세요.

## UX 가이드

- **`fetchContacts`는 페이지네이션** 방식입니다. 첫 호출 시 `offset: 0`, 이후 반환된 `nextOffset`을 순차적으로 사용하세요. `done: true`가 되면 더 이상 데이터가 없습니다.
- **`fetchAlbumPhotos`는 `maxCount`로 부하를 제어**하세요. 한 번에 너무 많은 사진을 요청하면 메모리와 속도에 영향을 줄 수 있습니다.
- **`contactsViral`은 cleanup 함수를 반드시 호출**하세요. 컴포넌트가 unmount될 때 반환된 cleanup을 실행해야 리소스가 해제됩니다.
