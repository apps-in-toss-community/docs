# `openPDFViewer`

Base64로 인코딩된 PDF 데이터를 기기 네이티브 PDF 뷰어로 엽니다. 사용자가 뷰어를 닫으면 `'CLOSE'`를 반환합니다. 계약서, 영수증, 안내 문서 등 PDF를 인앱에서 바로 표시할 때 활용할 수 있습니다.

## 시그니처

```ts
import { openPDFViewer } from '@apps-in-toss/web-framework';

declare const openPDFViewer: ((params: OpenPDFViewerParams) => Promise<'CLOSE'>) & {
  isSupported: () => boolean;
};

interface OpenPDFViewerParams {
  /** Base64로 인코딩된 PDF 데이터 */
  data: string;
  /** 뷰어에 표시할 파일명 (선택) */
  filename?: string;
}
```

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | :-: | --- |
| `params.data` | `string` | ✓ | Base64로 인코딩된 PDF 데이터입니다. |
| `params.filename` | `string` | — | 뷰어 UI에 표시할 파일명. 지정하지 않으면 기기 기본값으로 표시됩니다. |

## 반환값

- `Promise<'CLOSE'>` — 사용자가 PDF 뷰어를 닫으면 `'CLOSE'`로 resolve됩니다.
- devtools mock 환경에서는 즉시 `'CLOSE'`를 반환합니다.

## 권한

권한이 필요하지 않습니다.

## 예제

### 최소 예제

```tsx
import { openPDFViewer } from '@apps-in-toss/web-framework';

const result = await openPDFViewer({ data: base64PdfString });
console.log(result); // 'CLOSE'
```

### 실전 예제 — 서버에서 받은 PDF 열기

```tsx
import { openPDFViewer } from '@apps-in-toss/web-framework';
import { useState } from 'react';

export function ReceiptViewer({ receiptBase64 }: { receiptBase64: string }) {
  const [message, setMessage] = useState('');
  const [pending, setPending] = useState(false);

  async function openReceipt() {
    setPending(true);
    setMessage('');
    try {
      await openPDFViewer({ data: receiptBase64, filename: 'receipt.pdf' });
      setMessage('뷰어를 닫았습니다.');
    } catch (error) {
      setMessage('PDF를 열지 못했어요. 다시 시도해 주세요.');
      console.error(error);
    } finally {
      setPending(false);
    }
  }

  return (
    <div>
      <button type="button" onClick={openReceipt} disabled={pending}>
        {pending ? '여는 중...' : '영수증 보기'}
      </button>
      {message && <p role="status">{message}</p>}
    </div>
  );
}
```
