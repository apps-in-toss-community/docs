# Privacy

apps-in-toss-community tools (devtools, console-cli, agent-plugin, polyfill) do **not collect usage telemetry.**

This page previously described a two-tier telemetry system (Tier 0 opt-out daily ping / Tier 1 opt-in extended telemetry). Telemetry has been removed across the entire project, and the ingest server (`metrics-ingest`) has been retired. All related code has been stripped from every tool.

If telemetry is ever reintroduced, it will be via a clearly-documented consent flow and this page will be updated accordingly. No data is collected at this time.

Questions? Open a [GitHub Issue](https://github.com/apps-in-toss-community/docs/issues).
