# 프라이버시 — 익명 사용 텔레메트리

apps-in-toss-community 도구는 **opt-in**으로 익명 사용 텔레메트리를 수집합니다. 동의하기 전에는 어떤 이벤트도 전송되지 않습니다.

:::info 왜 수집하나요?
"1.0.0 안정 버전을 끊을 시점이 왔는가"를 판단하려면 다운로드 수 같은 표면 지표가 아니라 **실제 활성 사용자의 신호**가 필요합니다. opt-in 모델은 표본이 작지만 봇·CI 노이즈가 없어 신호 품질이 높습니다.
:::

## 수집 소스 (도구별)

| 도구 | 패키지 / 위치 | 현재 상태 |
|---|---|---|
| `@ait-co/devtools` | npm `@ait-co/devtools` | 활성 (`source: "devtools"`) |
| `@ait-co/console-cli` | npm `@ait-co/console-cli` | 미통합 (향후 추가 예정) |
| agent-plugin | Claude Code / Codex 플러그인 | 미통합 (향후 추가 예정) |

새 소스가 추가될 때마다 이 페이지의 도구별 섹션과 [metrics-ingest 저장소](https://github.com/apps-in-toss-community/metrics-ingest)의 `source` allowlist가 동시에 갱신됩니다.

## 수집하는 데이터

이벤트 하나는 다음 형태입니다.

```json
{
  "source": "devtools",
  "event": "panel_open",
  "anon_id": "<브라우저 localStorage에 저장된 무작위 UUID v4>",
  "version": "0.1.14",
  "ts": 1715423400000,
  "meta": { "tab": "iap" }
}
```

Worker는 Cloudflare가 제공하는 **국가 코드(`cf.country`, 2-letter)** 한 가지를 추가로 기록합니다.

### `@ait-co/devtools` 이벤트

| 이벤트 | 의미 |
|---|---|
| `panel_mount` | 도구 패널이 처음 마운트됨 (페이지 로드 후 1회) |
| `panel_open` | 사용자가 패널을 열음 |
| `tab_view` | 사용자가 탭을 전환함. `meta.tab` 라벨 포함 |
| `session_duration` | 페이지 unload 시점에 누적 사용 시간(ms) 전송 |

`meta` 객체는 도구별로 자유로운 JSON이지만 **256 바이트(JSON 직렬화 기준) 상한**을 넘으면 서버에서 거부됩니다.

## 절대 수집하지 않는 것

- **IP 주소** — 요청 처리에 일시적으로 보일 뿐, DB나 로그에 기록되지 않습니다
- **User-Agent 문자열**
- **개인 식별 정보** — 이름·이메일·전화·계정 식별자 등 일체
- **모의 호출 인자·사용자가 작성한 코드** — devtools가 mock하는 SDK 호출의 인자는 텔레메트리에 포함되지 않습니다
- **`cf.country` 외의 어떤 Cloudflare 메타데이터도 저장하지 않습니다**

## 보존 기간

이벤트는 **90일 동안만 보관**됩니다. 매일 UTC 03:00에 cron이 `now - 90일`보다 오래된 행을 일괄 삭제합니다.

## 동의 / 거부

기본값은 **opt-out**(전송하지 않음)입니다.

- 처음 도구를 열면 한 번 토스트가 뜹니다: "Yes (보낼게요)" / "No, thanks" / "더 알아보기" (이 페이지)
- "No, thanks"를 선택하면 **30일 뒤 한 번만** 다시 묻고, 그 이후로는 영구 침묵합니다
- 동의 상태는 언제든 도구 패널의 **Environment 탭** 토글로 변경할 수 있습니다
- 동의를 끄면 그 이후 어떤 이벤트도 전송되지 않습니다 (이미 보낸 데이터는 아래 "삭제 요청"으로)

저장되는 localStorage 키는 다음과 같습니다.

| 키 | 의미 |
|---|---|
| `__ait_telemetry:consent` | `granted` / `denied` / 부재 |
| `__ait_telemetry:reprompt_after` | 다음 reprompt 가능 시각 (epoch ms) |
| `__ait_telemetry:policy_version` | 동의한 정책 버전. 정책이 의미 있게 바뀌면 bump되어 reprompt 발생 |
| `__ait_telemetry:anon_id` | 브라우저별 무작위 UUID v4. cookie 아님 |

## 삭제 요청

자신의 `anon_id`에 연결된 모든 이벤트를 즉시 삭제할 수 있습니다.

1. devtools 패널 Environment 탭에서 **"내 anon_id 데이터 삭제"** 클릭, **또는**
2. 직접 호출:

```bash
curl -X DELETE 'https://t.aitc.dev/e?anon_id=<당신의-anon_id>'
```

`anon_id`는 브라우저 DevTools → Application → Local Storage → `__ait_telemetry:anon_id` 값으로 확인할 수 있습니다.

응답은 `{ "ok": true, "deleted": <삭제된 행 수> }`입니다.

## 인프라

수신 엔드포인트는 Cloudflare Workers로 구동되며 코드는 모두 공개되어 있습니다.

- 저장소: [`apps-in-toss-community/metrics-ingest`](https://github.com/apps-in-toss-community/metrics-ingest)
- Production 호스트: `t.aitc.dev`
- Staging 호스트: `t-staging.aitc.dev` (정책 검증용)
- 저장소: Cloudflare D1 (이벤트) + KV (rate limit 상태)
- 분당 IP 당 60요청 rate limit

스키마는 [`migrations/0001_init.sql`](https://github.com/apps-in-toss-community/metrics-ingest/blob/main/migrations/0001_init.sql), 검증 규칙은 [`src/lib/schema.ts`](https://github.com/apps-in-toss-community/metrics-ingest/blob/main/src/lib/schema.ts)에 있습니다.

## 정책 변경

이 페이지에 의미 있는 변경이 있을 때마다 `__ait_telemetry:policy_version`이 bump되어 도구에서 한 번 더 동의를 묻습니다. 단순한 오탈자나 표현 정리는 bump하지 않습니다.
