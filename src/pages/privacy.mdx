# 프라이버시

apps-in-toss-community의 도구(devtools, console-cli, agent-plugin, polyfill)는 **사용량 텔레메트리를 수집하지 않습니다.**

이전에 이 페이지는 두 계층 텔레메트리 시스템(Tier 0 opt-out 일일 핑 / Tier 1 opt-in 확장 텔레메트리)을 설명했습니다. 조직 차원의 결정으로 텔레메트리가 전면 제거됐고, 수신 서버(`metrics-ingest`)는 폐기됐습니다. 모든 도구에서 관련 코드가 제거된 상태입니다.

향후 텔레메트리가 재도입된다면, 명확한 동의 흐름과 함께 이 페이지에서 새로 안내합니다. 현재는 어떤 데이터도 수집되지 않습니다.

문의는 [GitHub Issues](https://github.com/apps-in-toss-community/docs/issues)로 남겨주세요.

## 변경 이력

| 날짜 | 내용 |
|---|---|
| 2026-06 | 텔레메트리 전면 제거, metrics-ingest 폐기 — 수집 정책 전부 삭제 |
| 2026-05-18 | single opt-in → multi-tier 재설계 (Tier 0 opt-out daily ping + Tier 1 opt-in 확장 텔레메트리) |
